# Examples

Each file is a worked output from following the skills for one invented organization. The request at the top of each file is what the agent was given. Every organization, funder, figure, and story here is invented, including the numbers the "organization" supplies. Don't reuse them.

These outputs were written by following the skills by hand, not recorded from a live run in an AI tool.

| Example | Skills used |
| --- | --- |
| [Food bank: foundation grant](food-bank-foundation-grant.md) | `npo-program-facts`, `npo-grant-proposal`, `npo-budget-narrative` |
| [Youth reading program: year-end donors](reading-program-donors.md) | `npo-impact-report`, `npo-donor-thank-you`, `npo-appeal-letter` |
| [Park cleanup day: event and volunteers](park-cleanup-volunteers.md) | `npo-event-plan`, `npo-volunteer-role`, `npo-volunteer-schedule` |

Use them to see what good output looks like, and as test cases when you change a skill: follow the changed skill with the same request and compare.
